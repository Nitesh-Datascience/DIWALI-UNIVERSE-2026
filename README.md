# ✨ Diwali Universe 2026 — CODLYTIC

A cinematic, responsive Diwali greeting experience built with HTML, CSS and JavaScript.

## Live preview
After enabling GitHub Pages, your site will be available at:
https://nitesh-datascience.github.io/DIWALI-UNIVERSE-2026/

## Features
- Golden cinematic landing page and responsive layout
- Animated starfield and glowing diya flames
- Interactive fireworks button plus ambient spark bursts
- Diwali greetings in English and Hindi
- No build step or package installation required

## Run locally
Open `index.html` in a modern browser.

## Publish with GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **main** and **/(root)**, then click **Save**.
4. Wait for the Pages deployment to finish.
